Note Tool Self-Test

Runs entirely on this computer. This page makes no network requests and stores nothing. Use only the made-up test values below, never real call data.

Part A: Test your note tool

Open your note tool in another tab and run each test. Record Pass or Fail in CHECKLIST.md.

#TestPass if
T1Type TEST-ONLY-ALPHA in a free-text field. Close the tab and reopen the tool.The field is empty.
T2With the tool open, press F12 > Application (Chrome) or Storage (Firefox). Look at Local Storage, Session Storage and IndexedDB for the file.No entries contain form text.
T3Fill a field and leave the tool idle for its stated timeout.The form clears itself. (Fail if the tool has no timeout.)
T4Press F12 > Network, reload the tool, fill and copy a note.No requests besides the file itself.
T5Type TEST in a field, reload, then type T again.The browser offers no autofill suggestion.
T6Enter each "Should block" value below into a free-text field and try to copy the note.Copy is blocked for every value.
T7Enter each "Should allow" value below and copy the note.Copy works (no false block).
